# Copiloto de Vendas com IA para Construção Civil

## Objetivo

Auxiliar vendedores no atendimento de clientes interessados em construção residencial.

## Problema Resolvido

Muitos clientes chegam sem clareza sobre:

- Custos
- Prazos
- Sistemas construtivos

O copiloto ajuda a qualificar e orientar esses clientes.

## Estrutura

- Prompt Principal
- Base de Conhecimento
- Tratamento de Objeções
- Perguntas Frequentes

## Exemplo

Cliente:

"Tenho um terreno de 400m²."

Copiloto:

"Ótimo. Em qual cidade está localizado o terreno? Qual padrão de construção deseja?"

## Melhorias Futuras

- CRM
- WhatsApp
- Integração com IA
- Geração automática de propostas
